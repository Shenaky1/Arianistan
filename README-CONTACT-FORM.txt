CONTACT FORM UPDATE

This version replaces the Outlook/mailto button with a real web form.

FIRST-TIME ACTIVATION
1. Deploy this package to the existing Cloudflare Worker.
2. Open https://arianistan.com/contact.html
3. Submit one test message.
4. FormSubmit will email an activation request to anwar@arianistan.com.
5. Open that email and click the activation/confirmation link.
6. Submit the test form again. Future inquiries will then arrive directly by email.

No Outlook or local email application is required.
