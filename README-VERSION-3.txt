ARIANISTAN REAL ESTATE — VERSION 3.0 FINAL

INSTALLATION
1. Extract this ZIP outside your GitHub repository.
2. Open the extracted arianistan-version-3.0-final folder.
3. Copy the CONTENTS of the folder—not the folder itself.
4. Paste into the root of your existing Arianistan repository.
5. Choose Replace files in the destination.
6. In GitHub Desktop, confirm the changed files are at the repository root.
7. Commit with: Deploy polished Version 3.0
8. Push origin. Cloudflare will deploy automatically.

This version keeps the original headshot, logo, exterior property image, and MLS interior photographs.
